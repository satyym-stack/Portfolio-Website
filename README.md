# Satyam Chaurasia — Portfolio Website

Personal portfolio website built with React, TypeScript, GSAP, and Three.js.

## Tech Stack

React • TypeScript • GSAP • Three.js • WebGL • Vite • CSS

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
